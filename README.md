# E-Commerce Management System

A two-person portfolio project built from beginner level with:

**Java • Spring Boot • PostgreSQL • Automated Testing • Docker • CI/CD • AWS • AI/RAG**

## Product
Customers can register/login, browse/search products, manage a cart, apply coupons, checkout, view orders, and cancel eligible orders. Admins manage catalog, inventory, coupons, orders, and users.

## Engineering focus
- Modular monolith
- REST API
- Spring Security + JWT/RBAC
- PostgreSQL + JPA/Hibernate + migrations
- Transaction-safe checkout and overselling prevention
- JUnit 5, Mockito, integration/API testing, Testcontainers, E2E
- Docker/Compose
- GitHub Actions
- AWS deployment
- Scoped AI/RAG store assistant

## Team workflow
Every implementation starts from an Issue and is developed on a branch. The partner reviews the Pull Request. CI must pass before merge.
