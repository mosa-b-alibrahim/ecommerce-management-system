# Sprint Plan

Use one-week Sprints aligned with the learning roadmap.

For every Sprint record:
- Learning goals
- Sprint goal
- Developer A Issues
- Developer B Issues
- Shared integration Issue
- Review swap
- Tests required
- Sprint Definition of Done
- Retrospective: what was learned, blocked, changed

## Example - Product Sprint
Shared learning: Spring REST + DTO validation.
Developer A: Product DTO/service/controller slice.
Developer B: Category slice + product-category contract.
Shared: integration/API checks.
Review: A reviews B; B reviews A.
Do not use this example before reaching the relevant roadmap week.
