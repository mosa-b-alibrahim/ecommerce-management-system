# Code Review Guide

Reviewer asks:
- Does the code satisfy Issue acceptance criteria?
- Is business logic in an appropriate layer?
- Are names understandable?
- Are invalid/unauthorized paths handled?
- Are database changes safe?
- Are tests meaningful, not just coverage?
- Could concurrency affect this feature?
- Are secrets/logging safe?
- Did scope creep into unrelated Issues?
- Does documentation need updating?

Review comments should explain the concern and, when possible, the reason. The author makes the fix and learns from it.
