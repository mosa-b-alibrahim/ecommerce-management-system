# START HERE

This repository is both:
1. the documentation for the E-Commerce Management System,
2. a 12-week beginner learning plan,
3. a two-person GitHub collaboration plan.

## First day
1. Read `PROJECT_CONTEXT_FOR_AI.md`.
2. Read `docs/01-project-overview.md`.
3. Read `docs/09-github-workflow.md`.
4. Read Week 1 in `docs/10-development-roadmap.md`.
5. Create the GitHub repository and invite the second collaborator.
6. Create the project board, labels, and high-level milestones.
7. Work only on the current Sprint.

## Learning rule
Learn -> small exercise -> project task -> test -> fix -> commit -> push -> PR -> partner review -> merge.

Do not ask AI/Codex to build the whole application. The purpose is to learn while producing a strong portfolio project.

## Learning vs project repository
This repository is the team's project workspace and source of truth for requirements, engineering decisions, implementation, tests and delivery. Detailed learning lessons, exercises and interview preparation are intentionally kept outside the repository.
